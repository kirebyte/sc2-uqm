# UQM Documentation - Menu System

Esta carpeta contiene documentación sobre cómo modificar y extender el sistema de menús en The Ur-Quan Masters (UQM).

## Documentos Disponibles

### 📖 [HOW_TO_ADD_MENU_OPTIONS.md](HOW_TO_ADD_MENU_OPTIONS.md)
**Guía Completa** - Tutorial detallado paso a paso para agregar nuevas opciones al menú de configuración de UQM. Incluye:
- Arquitectura del sistema de menús
- Explicación detallada de cada archivo involucrado
- Ejemplo completo con la implementación de "Cheat Mode"
- Consideraciones importantes y mejores prácticas
- Solución de problemas comunes

### ⚡ [MENU_OPTIONS_QUICK_REF.md](MENU_OPTIONS_QUICK_REF.md)
**Referencia Rápida** - Checklist condensado para desarrolladores que ya conocen el proceso:
- Lista de pasos esenciales
- Reglas críticas a recordar
- Comandos de testing  
- Problemas comunes y soluciones

### 📋 [CHEAT_MODE_IMPLEMENTATION.md](CHEAT_MODE_IMPLEMENTATION.md)
**Registro de Cambios** - Documentación específica de la implementación de Cheat Mode:
- Lista detallada de archivos modificados
- Cambios específicos realizados en cada archivo
- Detalles de implementación
- Lecciones aprendidas
- Resultados de testing

## Cuándo Usar Cada Documento

- **Principiante**: Comienza con `HOW_TO_ADD_MENU_OPTIONS.md`
- **Desarrollador experimentado**: Usa `MENU_OPTIONS_QUICK_REF.md`
- **Mantenimiento de código**: Consulta `CHEAT_MODE_IMPLEMENTATION.md` para entender cambios previos

## Contexto

Estos documentos fueron creados durante la implementación de una opción "Cheat Mode" en el menú de configuración de UQM, proceso que reveló la complejidad del sistema de menús y la importancia de mantener sincronizados múltiples archivos.
